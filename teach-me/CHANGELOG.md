# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.1] - 2026-11-26

### Changed

- Compressed the worked example to a five-line sketch; teaching loop and lesson
  anatomy are unchanged.

## [1.0.0] - 2026-11-26

### Added

- Session- or topic-driven course builder: infers material from recent diffs, commits,
  and evidence, or teaches a named topic.
- Lesson map up front (3–8 lessons, dependency-ordered), exactly one lesson per reply.
- Lesson anatomy: grounding in real artifacts, mechanics, the transferable principle,
  honest caveats, a single takeaway, and a handoff naming the next lesson.
- Learner adaptation: steady pace on repeated `next`, deeper or inserted lessons for
  hard questions, corrections update the map.
- Process close-out for shipped work, plus a worked example from a Tauri tray-mode
  session.
